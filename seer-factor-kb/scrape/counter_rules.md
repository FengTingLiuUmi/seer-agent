# 机制 → 反制 速查表（用于「为什么这样打」与自动规划）

原则（用户定案，勿改）：
- 31505 守御八方（表姐帝皇之御/3512 自爆）= **攻击技能，不受封属影响**；给全队「接下来 2 次用技能必定先手+必定暴击」。
- 必暴=必定暴击，本质「伪必中」：命中拉满 100%（**高闪避也照样中**）；只有己方被**专门降「命中」等级**时才不再必中。真·必中 > 必暴。
- 0×克制 = 打不出红伤，但技能效果仍触发。

## 常用组合套路
- **表姐自爆流**：帝皇之御(表姐) 自爆守御八方 → 后续 2 只吃到「必先+必暴」→ 接强攻手秒杀。适用被必先/封属/只吃暴击/免疫某一攻。
- **增伤链**：火潘(潘克多斯4344)+蒂朵+西塔伦+鲁肃 … 铺垫增伤后接强攻。
- **站场磨**：草潘(加尔鲁特4606)/村长(希可洛4487) 卡裸伤/叠毒磨。
- **弹伤**：鲁斯王(星光4648)、索比斯等反弹。

## 反弹：一套方案，不是两套（用户定案）
- **先手反弹**与**后手反弹**是同一「弹伤方案」的两种实现，区别只在「怎么让弹伤精灵取得出手/存活」，弹伤本体是同一件事。
- **不得把它们当成可互相替换的独立方案**；先手反弹没生效 ≠ 方案失败。
- 先手反弹未生效时：**禁止直接改跳后手反弹、更禁止改用户配置/阵容**。应先定位未生效原因（自爆没放出、必先次数被抢、命中/封属/Boss 免伤反弹、出场顺序、PP 等），在用户现有配置上修触发条件并重试。
- 只有 ①用户明确要求改用后手，或 ②关卡本身只允许后手（禁自爆/禁必先），才考虑后手反弹。
- **任何改阵容/改精灵的操作都必须先获用户同意。**

## 命中维度判断（别再犯）
- Boss **高闪避** → 必暴够用，**不要因此死磕必中**、放弃其它思路。
- 只有 Boss **明确标注「命中弱化/降命中」**（极少）→ 才补真·必中 或 解命中弱化。
