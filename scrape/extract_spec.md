# 因子关抽取契约（extract spec）

目标：把「一个帖子(thread)」里能读到的因子战斗数据，抽成结构化 JSON，供后续按因子去重合并、补 B 站、写本体、做「为什么这样打」解释。

## 输入
`scrape/batches/threads-batch-NN.jsonl`，每行一个帖子 JSON：
- `tid` 整数
- `typeid` 9=简单 / 10=困难 / 11=地狱
- `list_title` / `title` 标题
- `main_post` 楼主帖纯文本
- `posts` `[{pid, text}]` 第 1 页回帖纯文本
- `has_locked_hide` 是否有回复可见
- `attachments` 附件链接

## 输出（写入 `scrape/factor-extract/batch-NN.json`，UTF-8）
```json
{ "items": [
  { "tid": 3313, "factor": "伊塔回溯型", "difficulty": "地狱",
    "ban": ["王之哈莫","典韦","斯克鲁恩"],
    "stages": [
      { "stage": 1, "boss_type": "机械战斗", "boss_hp": 10000,
        "traits": "5%概率5倍伤；消强；每回合300固伤；随机弱化三项",
        "strategy": "魔钰强攻 / 丽莎强攻",
        "pets": ["魔钰","星光·丽莎布布"],
        "config": "漆黑+假面+洛林卡之星" }
    ],
    "note": "" }
] }
```

## 规则（宁缺毋滥，绝不编造）
- 因子名精确到进化形态（「无限·欧根尼克」≠「欧根尼克」）。
- 一个帖子讲多个因子（顿号并列）→ 拆成多条 item。
- `difficulty`：typeid 9/10/11 → 简单/困难/地狱；正文难度与 typeid 冲突时以正文为准并在 `note` 说明。
- 只抽正文明确写出的字段，缺就省略：`boss_type`(机械/机械战斗/邪灵龙/圣灵自然…)、`boss_hp`(整数)、`traits`、`strategy`、`pets`、`config`、`ban`。
- `traits` 保留机制关键词：必先/封属/N固伤/免疫物攻|免疫特攻/只吃暴击/消强/吸强(偷强)/两命/多命/免死/裸伤上限/面板免疫/护盾/盾罩/清PP/断回合/命中弱化/闪避/随机弱化/全属性+1/吸血/回血/月亮/暴食/必暴/必中/秒杀/具体异常名。
- `strategy`=怎么打（方案用 `/` 分隔）；`pets`=方案用到的精灵名（不含套装称号火）；`config`=套装/称号/火焰/药剂。
- 帖子是「合集 / 只有下载链接 / 仅截图 / 无关卡信息」→ 保留 factor+difficulty（能判定就写），`stages:[]`，`note` 写「合集 / 无正文数据 / 仅截图」等。
- 简称映射（别改错）：潘=潘克多斯、火潘=潘克多斯、草潘=加尔鲁特、冰潘=斯克鲁恩、王哈=王之哈莫、艾欧=艾欧丽娅(老形态)、鲁斯王=星光·鲁斯王、猩猩=星光·魔焰猩猩、丽莎=星光·丽莎布布、村长=希可洛、眠酱=眠降·玛缇娜、表姐=帝皇之御、地王=混沌地王莱茵哈特、月照=月照星魂、界皇=幻境界皇。

## 汇总回复（给编排器）
一行 JSON：`{"processed":N,"factors":M,"skipped":K}`（processed=处理帖子数，factors=产出 item 数，skipped=无法抽取的帖子数）。
