## 补齐方式

1. **取数**（每只一条，字段已确认存在）：
   ```
   seerapi get pet <id> --fields id,name,type,base_stats,skill,soulmark,factor
   ```
   - `type` → 本体 `hasTypeCombination`
   - `base_stats` → 种族值
   - `skill` / `soulmark` → 技能 / 魂印（可选）
   - `factor` → 是否因子精灵

2. **入库**：走 `seer-factor-kb/ontology/ingest.py`（或 `ingest_factors.py` / `ingest_typechart.py` 对应分支）。

3. **补定位**：`pve:hasRole`（强攻/辅助/站场/弹伤/必先）SeerAPI 通常没有，需要：
   - 规则推导（属性+技能机制），或
   - 人工标注，或
   - 先留空并在查询时返回「定位未标注」

4. **补简称**：`skos:altLabel`（社区简称，如「村长」「火潘」）——新增精灵通常还没有社区简称，留空即可，`nick` 已有精确匹配防误配。
