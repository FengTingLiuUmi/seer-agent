# 八四公式

简单多精灵关的通用解法（已真机验证）：

**帝皇之御 31505 守御八方（自爆 → 己方接下来 2 次使用技能必定先手、必定暴击）→ 1 级六界 19314 剑挥四方（弹伤 → BOSS 到 1 血）→ 时空界皇 31253 时空跃迁术（必先补刀）**

## 命令形态

```bash
python -m seer_rebuild.cli factor --stage <N> --design-id <id> \
  --skill "31505,19314,31253" --switch "<六界catch>,<时空catch>" --send --write
```

`--switch` 比 `--skill` 少 1（第 1 招用首发场上精灵）。

## 注意

- 对**单命 BOSS**：六界弹到 1 血 + 补刀收。
- 对**2 命 BOSS**：八四只够处理 1 条命，命2 要换强攻手收（见 [[多命BOSS]] / [[强攻手选型]]）。
- 六界要压到 **1 级**（弹伤量随差额最大化时更稳）。
