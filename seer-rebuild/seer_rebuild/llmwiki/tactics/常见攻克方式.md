# 常见攻克方式

> ⚠️ 本页列的是**常见套路示例与思路**，不是穷举清单，也不是照抄即通的公式；每条里的精灵/技能只是举例。具体某关以该 BOSS / 因子关的实战配方为准。

术语口径以 [[必中与必暴]]、[[必先与先制]] 为准。

## 1. 必先强攻

精灵通过机制让**大威力技能必先出手**，达成先手击杀 BOSS。一般需要**压体（低血量）**；单精灵一般配**漆黑套**，多精灵一般配**银翼套**。

- **魔钰**：梦境残缺 —— 低体下必定暴击，伤害 3 倍。
- **月照星魂**：月下华尔兹 —— 低体下必定暴击，伤害 3 倍。

## 2. 八四公式 / 表姐强攻

表姐（帝皇之御）用 **31505 守御八方** 给后续精灵提供**必先 + 必暴**，让六界 / 强攻手拿到出手权，强攻手再打出高威力克制技能。

> 31505 是整队级 buff：接下来 2 次技能必先必暴，跨换宠持续；必暴是「伪必中」（己方受命中弱化时就不再必中）。详见 [[必中与必暴]]。

**六界用法补充**：
- 六界一般 **1 级**，与 BOSS 存在较大属性差；只要**先手释放剑挥四方(19314)**，就能把 BOSS 造成的高额伤害反弹回去。
- 无法攻克的场景：
  1. 关卡只能 **100 级**（六界压不到 1 级）；
  2. 自身属性过高 → BOSS 打出的伤害太低，弹不死；
  3. **多命 BOSS** → 需补强攻收尾（见 [[多命BOSS]]）；
  4. BOSS 有**击杀回血**。

**蒂朵替代表姐（必先，但更弱）**：
- 同理也可让**蒂朵**提供必先：**只有一次**、且**非必暴**（35914 幻梦芳逝＝给下只首次技能必先 + 真必中，见 [[必中与必暴]]）。
- 蒂朵自身无免死，需其它精灵配合让其能放出技能。

## 3. 单精灵站场

靠精灵自身的**减伤 / 机制**让 BOSS 打不死当前精灵，磨死 BOSS。

示例：圣灵谱尼（技能 / 魂印回血 + 不受控制）、星光·丽莎布布、草潘。

## 4. 站场强攻

现在比较少见的打法，两种形态：

1. **简单关卡**：直接星光·鲁斯王第五强攻（两命，伤害高）。
2. **保血线型**：先由天河神将 / 索比斯给 BOSS 消强（非必须；BOSS 一般开场带攻击强化 +2），再用草王等保住强攻手血线，使其能放出技能。

## 5. 星巴克公式

克罗给**星光·魔焰猩猩**上减伤 → 猩猩能出手给 BOSS**上魂印固伤**，再由**星光·鲁斯王**两命下的克制弹伤击败 BOSS。

- 克罗减伤**非必须**；核心是让猩猩能对 BOSS 上魂印。
