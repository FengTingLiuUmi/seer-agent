# 伊娜 简单难度 复盘

简单难度无「不可重复上阵」，同一只精灵一场可连打多回合。

## 通用解法（真机验证）

**圣灵谱尼 solo：`25679 光荣之梦` → `31143 神灵救世光` 交替磨**。

- 25679：全属性+1（对手非混沌则翻倍）+ 下两回合先制+2 + 回 1/2 体力。
- 31143（第5招 160 威力）：靠 25679 的先制+2 抢在 BOSS 必先前出手；消回合 → 3 回合禁回血 + 吸 200 固伤 + 未击败叠百分比。
- 第 1-4 关都能谱尼 solo；第 4 关塔尼瓦(地面龙)若危险用八四。
