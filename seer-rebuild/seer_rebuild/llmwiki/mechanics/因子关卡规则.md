# 因子关卡规则

因子关卡模板化：**简单/普通/困难三难度，各 5 个 BATTLE**。第 3 关通常是**单精灵对战（1v1，不能 2407 换宠）**，其余为多精灵。
在困难/地狱模式下 boss可能存在隐藏特性，常见的有**每回合回血**,**多命**,**只/不吃暴击伤害**,**只/不吃特攻****只/不吃物攻**等 此类特性需要根据战报推断，而不是瞎猜

## 核心限制

- **普通难度**：每场 **6 回合内击败** + **不可重复上阵**（过关会锁本关出战阵容的 catch_time）。
- **困难难度**：BAN 选三只；一次挑战输 3 次整关输。
- **简单**：无「不可重复上阵」，同一只精灵一场可连续行动多次（谱尼连打 8 回合）。

## 推进 / 锁定（46046 三键）

- 键 `[progress_value, time_value, fail_times]`。
- `progress` 低 16 位 = 难度标记（`0x100` 简单 / `0x200` 普通 / `0x400` 困难），高 16 位 = 本难度已过关数。
- 可选择3种难度进行，在放弃/打完改难度一轮前不可更换难度；**打到普通时简单不能再打**（再进报 1905004）。
- **只有过关才锁本关出战精灵**；战败/未过关不锁，可复用。

## 判定

- 单精灵关 S2C 2503/2504 体积更小（约 924B/442B），可据此识别。
- 有 **45827** 才是过关；无 45827 只有 2506 = 战败/未过关。
- `42390` 只是「战斗结束」，胜利/战败都会发，**不能当过关**；只有 45827 / 敌血结算=0 才算过（曾把 42390 误判成「胜利」，造出假过关）。
