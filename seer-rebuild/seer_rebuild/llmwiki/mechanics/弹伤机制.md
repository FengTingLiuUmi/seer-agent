# 弹伤机制

弹伤（反弹）把 BOSS 造成的伤害反弹回 BOSS 自己。核心打手是**六界**_剑挥四方(19314)_，常用在 [[八四公式]] 里。

## 一种方案，两种触发方式

> 反弹是**一套方案**；先手 / 后手只是它的**两种不同实现**——区别只在「怎么让弹伤精灵取得出手 / 存活」，弹伤本体是同一件事。先手反弹未生效 ≠ 该方案失败：**不要**因此跳到后手反弹，更不要改用户阵容；应先定位未生效原因（自爆没放出、必先次数被抢、命中 / 封属 / BOSS 免伤反弹、出场顺序、PP 等），在现有配置上修触发条件再试。只有用户明确要求、或关卡只允许后手（禁自爆 / 禁必先）时，才考虑后手反弹。

- **先手反弹**：帝皇之御 31505 / 蒂朵 35914 / 幻影蝶等自爆必先精灵，给弹伤精灵先手权后手出弹伤。
- **后手反弹**：借 658 锁伤 + 34 复位（神寂·克罗诺斯等），赌回神/顽强特性后手弹死。

## 对多命 BOSS 的结算（关键）

弹伤反映一个实际伤害量；「剩 1 血补刀」只在**最后一条命**出现：

- 目标是**最后一条命** → 弹伤把它定格在 **1 血**，需补刀收。
- 目标**不是最后一条命**（后面还有命）→ **整条命被直接弹掉**（不剩 1 血）。

所以 2 命 BOSS 优先：**弹掉命1（直接死）→ 强攻手伤害 > 命2 满血收命2**；省弹伤手。

## 注意

- 「不吃暴击」（免致命一击伤害）的 BOSS：可以弹，但不能用表姐/漆黑直接强攻。
- 「免伤反弹致命伤」的 BOSS：自爆效果生效、**六界无法生效**。
