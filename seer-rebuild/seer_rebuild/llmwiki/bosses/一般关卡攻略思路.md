一.关卡全局信息收集
1. 尝试检索相关攻略 获得外部已经整理好的阵容 装备 思路 关卡等信息，尽可能多几个 以适配账号的配置。可以多尝试几种分词搜索方法和搜索源 核心通过精灵名定位
网络上的攻略大多以 地狱关卡(hard)模式为主。能够收集到 几个信息 boss的隐藏特性 以及处理的阵容和方式等。
在一般情况下 攻略思路呈现更难的能兼容容易的 ， 但是容易的关卡不一定要按照困难的来。
2. 读 BOSS：`factor_design`（`seerapi get factor_design <design_id>`）拿当前关的**规则**（6回合/不可重复上阵/封属/断回合）与**特性 desc**；再读 `04-codes.md` / `05-boss-traits.md` 查对应机制。
除了直接读取到的特性外 赛尔号还喜欢给boss上各种奇怪的隐藏特性 见 `seer\seer-rebuild\seer_rebuild\llmwiki\bosses\常见的隐藏特性.md`

二.阵容规划
根据收集到的信息，规划每一关的阵容和装备。可用的账号上精灵信息可用`python -m seer_rebuild.roster_cache` 或 `seer_rebuild/roster_cache.py` 的 `station_tanks()` / `attackers(stype=...)` 从 `.roster_cache` 选（静态类型/种族值 + 动态等级/技能 + SqliteKB 标签三层 JOIN）。
从规划上可以考虑每一关多几种方案

**选人铁律（不破这条，否则会重蹈「用龙鹰打邪灵暗影」覆辙）**：
强攻手/站场主C **必须先过属性克制闸**才许上场——`mult(技能属性, boss属性) > 1`，或在本关 `counteredBy` 列表里。只按「角色=强攻」或持有量选人而不同时查克制 = 必翻车。反例：神圣龙鹰=光/次元，次元对 暗影·邪灵 是 0.5×（半减），属性不中，不许上。

**阵容决策必须可解释（选谁、为什么、为什么不是别的）**：每只出战精灵落一条决策链，落盘后再发招——
① Boss 硬门/特性（SSOT traits + factor_design desc）→ ② 本难度规则（6回合 / 不可重复上阵 / 100级 / BAN）→ ③ 候选属性克制倍率（`mult(技能属性, boss属性)`）→ ④ 机制适配（这套为什么绕得过①②）→ ⑤ 持有个体与等级 → ⑥ 最终选择 + 一句「为什么是它、为什么不用备选」。
只写「强攻/站场」角色标签而缺 ②③④⑥ = 不合格，视为未选人。（反例教训：同一个 幻境界皇先3，在地狱是「免疫威力>100 逼低威力」的正解，在困难却要核对「6回合能不能打死」——不写这条链就会把两档方案混用。）

三.正式执行
1. **精简阵容 + 换装/称号 + 领火**：只放本关确实要用的（过关会锁阵容所有 catch_time）；按战术换套装/称号（一般 强攻=银翼+星光铸就者(591)，站场=漆黑+神话(300) 但也需要看情况调整）。
   **先查火并领绿火**：`python -m seer_rebuild.cli flame status` 看剩余；没火或快到期就 `flame claim --flame 6 --send`。绿火 = 每次登场全属性+1，可与西游四件套羁绊（首发全属性+1）叠成全属性+2，是强攻最容易被漏的增伤；别等打完了才发现没火。
   **组队按机制选等级（不是一律满级）**：先 `pet-level --catch-time <候选逗号分隔>` 查等级。
   - 强攻 / 站场 / 辅助 → 选 **lv=100**（面板最高）。
   - 弹伤 / 反伤本体（如六界帝神：第五先把所受攻击 100% 反馈，魂印靠「体力低于对手」触发全属性+1、下回合先制+2）→ 故意用 **1 级 / 压血**，保证体力远低于 Boss，弹伤与自身面板无关，反而等级越低越稳。
   别一律选满级，也别一律排除 1 级——先看这精灵靠不靠面板。
2.打每一关 ， 可能会因为boss隐藏特性以及配置等问题导致无法正常攻克。核心还是对战中的反馈来，比如boss在受到反弹后突然回满血 可能就是多命，部分技能无法造成伤害 可能就是免疫/只吃部分类型的攻击
这时就需要记录可能 更换阵营验证。
3. 出招序列定好后，`factor --stage N --design-id <id> --difficulty 1/2/3 --skill ... --switch ... --send --write --report-dir ...` 真打，逐回合看 2505 血量；**有 45827 才是过关**。难度锚定本体：`1=简单(easy) / 2=困难(normal) / 3=地狱(hard)`（地狱≠2）。进战后回读 2503 的 boss 物种/血量对 SSOT 的 `boss_pet_id/boss_hp`：对不上就是打错难度，停下别发招。
