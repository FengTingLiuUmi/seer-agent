# 伊娜 (4964)

伊娜因子第5关本体，属性 **地面·超能**。特性：先制 +3 + 每回合回血 + 固定伤害（**无减伤**，伤害不足是我方缺增伤，不是 BOSS 减伤）。

## 已验证配方（真机通关）

- 套装换 **漆黑天使 448**（全属性+50 / 攻伤+40% / 首发 300 护盾 / 首发首攻必暴），保留漫游者-AH 目镜；
- 首发圣灵谱尼 + 西游四件套羁绊（首发全属性+1）+ 启灵元神（首发护盾）+ 称号「夏日狂想曲」417；
- **出招连续打 `31143 神灵救世光`，不要插 `25679 光荣之梦`**：
  - 31143 的「消回合 → 3 回合禁回血」锁死伊娜每回合回血；+吸 200 固伤 + 未击败叠百分比，越打越疼。
  - 25679 的先制+2 对先制+3 是浪费回合。
